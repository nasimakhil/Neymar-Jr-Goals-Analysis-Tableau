# Neymar Jr. Goals Analysis Dashboard – Tableau

An interactive Tableau dashboard analyzing Neymar Jr.'s goals across different years, clubs, competitions, venues, goal types, and assist providers.

## Dashboard Preview

![Neymar Jr. Goals Dashboard](images/neymar-goals-dashboard.png)

## Dashboard Highlights

- Total Goals
- Penalty Percentage
- Win Percentage in Matches with a Goal
- Goals by Goal Type
- Top 5 Assist Providers
- Goals by Club
- Goals by Competition
- Goals by Venue
- Goals Trend by Year
- Year and Club filters

## Key Dashboard Metrics

- Total Goals: 377
- Penalty Goals: 18.3%
- Win % in Matches with a Goal: 79.4%

## Tools Used

- Tableau Public
- CSV
- Data Visualization
- Dashboard Design

## Dataset

The dashboard uses a Neymar Jr. goals dataset containing information such as:

- Date
- Year
- Tournament
- Competition Type
- Venue
- Club
- Opponent
- Match Outcome
- Minute
- Goal Type
- Penalty
- Assist Provider
- Goals
